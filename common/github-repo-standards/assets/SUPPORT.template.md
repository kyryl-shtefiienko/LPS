# Support

## Before asking

- Check the [README](README.md) and, if this project has one, the `docs/` directory.
- Search [existing issues](../../issues) and [discussions](../../discussions) — your question may already be answered.

## Asking a question

- **Usage questions / "how do I...?"** → open a [Discussion](../../discussions) (or an issue labeled `question` if Discussions isn't enabled).
- **Something is broken** → open an [issue](../../issues) using the bug report template.
- **Security issue** → do **not** open a public issue — see [SECURITY.md](SECURITY.md).
