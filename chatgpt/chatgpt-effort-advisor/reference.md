# ChatGPT model and thinking reference

Verified 2026-09-17. This snapshot is guidance, not a permanent model catalog. Refresh it from official OpenAI documentation when exact current availability, labels, or costs matter. Use the user's visible options for their account; do not infer access from an API model list or the host Codex session.

## ChatGPT mapping

| ChatGPT choice | Model mapping |
|---|---|
| Instant | GPT-5.6 Sol on eligible paid plans; GPT-5.6 Luna on Free/Go |
| Medium / High / Extra High | GPT-5.6 Sol |
| Think on Free/Go | GPT-5.6 Luna |
| Pro | GPT-5.6 Sol Pro or GPT-6 Pro, where offered |

GPT-6 Pro uses GPT-6 Astra. Plus offers Medium and High; Extra High and Pro require eligible plans. Workspace controls and rollout can affect access. Terra and Luna are not separate selectable models in standard ChatGPT chats. Work, Codex, and API availability are distinct.

Source: [GPT-5.6 and GPT-6 Pro in ChatGPT](https://help.openai.com/en/articles/20001354-gpt-5-6).

## Cost and effort

Under the documented Business/Enterprise/Edu credit schedule, Medium, High, and Extra High share the same per-message rate. Reducing effort therefore need not save credits. Subscription allowances and API token billing must be evaluated separately.

Source: [ChatGPT rate card](https://help.openai.com/en/articles/11481834).

## Handling change and uncertainty

When browsing is available, open the current official page rather than relying on a search snippet. If documentation and the user's controls disagree, recommend an option actually offered and acknowledge the mismatch. If browsing is unavailable, label the mapping as dated and keep recommendations conditional. Avoid repeated research when the same session already established the relevant options and there is no reason to suspect change.

Do not map ChatGPT's labels to API reasoning values by analogy. Do not carry across Claude commands or Codex effort levels. For an explicit API or Codex request, use guidance for that product instead of treating this table as portable.

The routing rubric and escalation choices in SKILL.md are this advisor's heuristics, not OpenAI benchmark results. They balance expected difficulty and the user's priorities without asserting fixed performance gains, token multipliers, or guaranteed accuracy.
